# Employee Directory Manager

A web-based Employee Directory Management System developed using Python Flask and SQLite.

## Project Overview
The Employee Directory Manager is designed to manage employee information efficiently. It provides a simple web interface to add, view, search, update, and delete employee records.

## Features
- User Login and Authentication
- Add New Employees
- View Employee Records
- Search Employees by ID or Name
- Update Employee Details
- Delete Employee Records
- Sort Employee Records

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS

## Installation and Setup

1. Clone the repository.
2. Install the required dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `py app.py`
4. Open your browser and visit:
   `http://127.0.0.1:5000`
